# Репит.центр — фронтенд

Публичный снимок разработки React-сервиса персонального обучения по макетам Figma. Здесь команда может посмотреть исходный код, текущие возможности и результаты проверок.

## Что готово

- Адаптивный публичный лендинг с предварительным рендерингом для SEO.
- Авторизация и онбординг, кабинет, создание и согласование учебного плана.
- Учебный маршрут, материалы, база знаний и интерфейс AI-репетитора.
- Экзамены, итоговый проект и демонстрационный диплом.
- Настройки профиля, доступности и акцентного цвета.
- Тарифы и демонстрационные сценарии подписки.

Серверные сценарии сейчас демонстрируются через MSW. Реальный AI, платежи и отправка писем не подключены. Репозиторий содержит фронтенд; backend разрабатывается отдельно. Некоторые расширенные настройки ещё находятся в плане.

## Посмотреть локально

Требуется Node.js 24.14+ (ветка 24) и npm.

```sh
git clone https://github.com/Meiraline/repeat-ai-frontend.git
cd repeat-ai-frontend/frontend
npm ci
npm run dev:mock
```

Откройте http://127.0.0.1:3000. Демонстрационный вход: `student@example.test` / `Repeat123` — это только тестовые данные.

## Структура и проверки

React, TypeScript, Vite, React Router, TanStack Query, CSS Modules и Atomic Design. Код находится в `frontend/`, документация — в `docs/`, инструкции и планы — в `ии-хелперы/`.

```sh
cd frontend
npm run check
npm run build-storybook
npx playwright install chromium firefox webkit
npm run test:e2e
npm run test:e2e:production
```

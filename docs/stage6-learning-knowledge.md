# Этап 6 — обучение и база знаний

21.09.2026. Реализован основной frontend-сценарий на изолированном mock API. Подключение реального сервера и полное соответствие всем вариантам Figma остаются открытыми.

## Проверить вручную

Запустить `npm run dev:mock` из `frontend`, открыть http://localhost:3000, войти как `student@example.test` / `Repeat123.`. Создать курс, пройти интервью, сформировать и утвердить программу. Нажать «Начать обучение».

1. Открыть первую тему карты. Остальные темы объясняют причину блокировки.
2. Раскрыть конспект и отметить изучение. Для непроверенного материала требуется подтверждение. После перезагрузки отметка сохраняется.
3. Изучить оба обязательных материала: тема становится готовой к контрольной точке. Снятие отметки возвращает её в процесс изучения.
4. Открыть самопроверку, показать ответ, выбрать «Знаю» или «Нужно повторить». Эти отметки сохраняются отдельно от учебного прогресса.
5. В базе знаний проверить поиск, фильтры и возврат к списку. Фильтры сохраняются в URL, в том числе после перезагрузки.

## Структура и маршруты

| Маршрут | Назначение |
| --- | --- |
| `/app/tracks/:id` | Карта и список тем, поиск, причины блокировок |
| `/app/tracks/:id/topics/:topic` | Урок, материалы и отметки изучения |
| `/app/tracks/:id/knowledge` | Записи курса, поиск, фильтры и самопроверка |
| `/app/knowledge` | Поиск среди активных курсов и переход к их знаниям |

`features/learning` и `features/knowledge` содержат схемы Zod, запросы и ключи кеша, привязанные к сессии и треку. Страницы связывают их с UI. Молекула `RoadmapTopic` и организм `LearningContent` не знают об API. Общие стили учебных страниц находятся в `pages/study`.

Структурированный контент поддерживает текст, заголовки, списки, код, таблицы и ссылки. HTML из данных не исполняется. Внешние ссылки допускают только абсолютные HTTP/HTTPS URL без логина и пароля; небезопасные и помеченные broken ссылки не открываются. Длинный код и таблицы прокручиваются внутри блока.

## Предварительный API

Все пути ниже начинаются с `/__preview/tracks/:id` и запрещены адаптером вне mock-режима. Это **не подтверждённые endpoint backend**.

| Метод и суффикс | Данные |
| --- | --- |
| GET `/` | Трек, версия, модули, темы, статусы и прогресс |
| GET `/topics/:topic` | Тема, материалы и доступ к контрольной точке |
| PUT `/topics/:topic/materials/:material` | `{ completed, expectedVersion }`, ответ — урок |
| GET `/knowledge` | Записи, версия программы, источники и самооценки |
| PUT `/knowledge/:entry` | `{ rating: "repeat" \| "known", expectedVersion }`, ответ — запись |

Изменения требуют `Idempotency-Key`: повтор потерянного ответа возвращает сохранённый результат, повтор ключа с другим содержимым отклоняется. Конфликт версии даёт 409 и предлагает загрузить сохранённое состояние. Обработчики проверяют сессию, владельца трека и блокировку темы; прямой запрос не обходит запрет. Preview-данные хранятся в `sessionStorage` отдельно для каждой тестовой личности, переживают reload, но не являются серверным хранением.

Для воспроизведения потери ответа установить `sessionStorage['repeat-preview-learning-response']` в `materials` или `knowledge`. Следующая соответствующая запись сохранится, но ответ вернёт 503; повтор с тем же ключом не создаёт новую версию.

## Границы реализации

- Mock-программа пока плоская, поэтому темы объединены в один модуль. Ветвящийся граф, полный модульный контракт и все варианты макетов не завершены.
- Прогресс явно подписан «Изучено материалов». Он не означает сдачу экзамена. Самооценки не открывают следующую тему. Формальные экзамены и разблокировка после их сдачи относятся к этапу 8.
- Конспект и самостоятельная практика обозначены демонстрационными. Источники берутся только из утверждённого плана; при отсутствии источников или терминов показывается пустое состояние. Реальных AI-материалов и AI-оценивания здесь нет.
- Общая база показывает активные курсы; поиск по содержимому всех курсов, архиву, серверная пагинация и восстановление позиции списка при кнопке возврата требуют дальнейшей реализации. URL-фильтры уже сохраняются.
- Последний доступный исторический backend-снимок `12bfd8579e65799117187445bd8fca508af0c43b` имеет другие DTO и считает прогресс трека через сданные темы. Его нельзя подключить заменой base URL.
- Fetch ветки `repeat-center` 21.09.2026 вернул **`de08e1d420239bc63bdded2355e29418e926c5f2`**. Исходники заменены gitlink `repeat-center` на `8610da119e9470a98700177785c6f23a82ebcbb3`, файл `.gitmodules` отсутствует. Актуальный исходный backend/API пока недоступен по этому дереву; у пользователя запрошен новый адрес. Локальные backend-файлы не менялись.

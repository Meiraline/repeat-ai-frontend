# Этап 9: безопасность и копия настроек

Figma: `5697:26469` (безопасность), `5292:17520` (приватность), страница «Прототип Десктоп MVP». На `/app/settings` добавлены две секции и ссылки навигации. Переиспользуются Button, Dialog, токены и CSS Modules. Это частичная реализация экранов по доступным контрактам.

## Безопасность

- Ссылка на существующее восстановление пароля по email. Прямая смена пароля, 2FA, список устройств, журнал входов и отзыв отдельной сессии не подключены.
- Выход из всех сессий после подтверждения: `POST /logout`, `{ allSessions: true }`. Обычный выход из оболочки сохраняет `{ allSessions: false }`.
- В отличие от кнопки «остальные сессии» в Figma, доступный контракт завершает также текущую. Интерфейс и подтверждение прямо указывают это различие.
- Ошибка не очищает клиентскую сессию и не выдаёт сообщение об успехе. Повтор запускается явно пользователем. 401 при выходе из всех сессий не считается подтверждением глобального отзыва; пользователь возвращается на вход. При обычном выходе 401 по-прежнему означает, что текущая сессия уже закрыта.
- Mock завершает только сессию текущей вкладки; мультиустройства не имитируются. Переключатель `repeat-preview-logout-response` в sessionStorage: `error` — 503 без записи, `lost` — 503 после завершения сессии. Оба одноразовые.

Параметр подтверждён историческим снимком `src/schemas/auth.py` и `src/api/v1/auth.py`. Работа с актуальным живым backend пока не проверена. Изменений backend нет.

## Приватность

Кнопка скачивает `repeat-settings.json`: загруженный профиль, применённые настройки устройства и наставника. Черновики форм исключены. JSON формируется в браузере, не отправляется на сервер. Разрешённые поля выделяются схемами Zod; неизвестные поля, включая случайно попавший token, удаляются. Пароли, сессии, история чата и учебные данные не читаются из хранилища для экспорта.

Интерфейс сообщает лишь передачу файла браузеру, не подтверждает запись на диск. Ошибка подготовки отображается отдельно. URL Blob освобождается после начала загрузки.

Это дополнение к макету и **не полный архив аккаунта**. Полный архив, хранение истории, персонализация и удаление аккаунта явно обозначены как неподключённые. Исторический API удаления имеет создание и отмену заявки, но не получение её статуса для перезагрузки/потери ответа; согласование этого сценария остаётся зависимостью. Юридическая ссылка ведёт на существующую страницу со статусом предоставления текста, не на выдуманную политику.

Следующие части этапа 9: оставшиеся настройки оформления (тёмная тема, плотность); серверные операции приватности требуют согласованного API. Этап 9 целиком остаётся открытым.

Проверки: `npm run check` — 58 unit-тестов, типы, линтер, форматирование и сборка успешно. Финальный браузерный прогон — 45/45, production — 2/2, Storybook — успешно. Проверены мобильная ширина 320 px и текст 200%, просмотрены QA-снимки. [Матрица](compatibility-matrix.md).

В ходе браузерной проверки исправлены два дефекта: возврат фокуса к кнопке после закрытия Dialog в WebKit (кнопка явно получает фокус перед открытием) и переполнение длинных значений select наставника при тексте 200% в мобильном WebKit. Select сохранил нативную семантику; оформление использует `appearance: none`, ограниченную сетку и существующую оригинальную стрелку `chevron-down.png`. Переполнение страницы не скрывается.

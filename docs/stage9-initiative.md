# Этап 9 — инициативность наставника

21.09.2026. Продолжен блок `/app/settings#mentor` по экрану Figma `6043:13404` («Прототип Десктоп MVP»). Перед изменениями повторно получены design context и изображение. Переиспользован атом Checkbox; новые изображения и зависимости не добавлены.

## Реализовано

- «Предлагаемые подсказки» — добавляет пример следующего вопроса.
- «Проверять понимание» — добавляет вопрос для самостоятельной проверки без оценки знаний.
- «Предлагать практику» — добавляет пример практического задания.

Это параметры демонстрационного чата: дополнения явно помечены демонстрационными и формируются mock-обработчиком. Реальный AI и содержательная оценка не подключены. Переключатель «Быстрые ответы», стиль общения и расширенные правила остаются в плане.

## Сохранение и совместимость

Модель `MentorPreferences` расширена булевыми `suggestNext`, `checkUnderstanding`, `suggestPractice`. В прежних записях без этих полей они получают `false`: обновление не включает дополнительную инициативность самовольно. Общие сохранение, отмена, сброс и сообщение об ошибке локального хранилища действуют на новые поля.

Параметры входят в снимок каждого сообщения. Восстановление частичного ответа использует исходные значения, даже если настройки уже выключены; следующий новый ответ использует новый выбор. Прежние снимки нормализуются перед сравнением идемпотентности, поэтому добавление полей не создаёт ложный 409. Повтор ключа с другими параметрами по-прежнему отклоняется.

Хранение остаётся локальным для браузера; серверный профиль и онбординг не изменяются. Все preview-маршруты остаются заблокированными вне mock-режима.

## Адаптация и проверки

Успешно: `npm run check` (44 unit-теста), Storybook build, 40 браузерных сценариев в пяти конфигурациях (включая 320 px и текст 200%) и 2 production-проверки. Снимки desktop и 320 px просмотрены.

Группа полей использует legend, подписи и связанные описания. На узком экране checkbox располагается над подписью, чтобы текст 200% не сжимался в узкую колонку. Использован существующий доступный Checkbox вместо новой реализации визуального toggle из Figma.

Проверяются миграция прежних значений, валидация boolean, сохранение после перезагрузки, появление всех трёх дополнений, отсутствие их в новых ответах после отключения и сохранение исходного набора при восстановлении. Сценарии настроек и чата включают ширину 320 px и текст 200%. Снимки обновлены в `docs/qa/stage9-mentor-*`. Реальный AI и физические устройства не проверялись.
